# TVC Website --- Information Architecture

## Primary navigation

Recommended top-level navigation: - Home - Events - Speakers - Team

Use the TVC logo as a home link. Keep the navigation compact. On mobile,
use an accessible menu with a clear open/close state.

## Sitemap

``` text
Home /
├── Events /events
│   ├── TVC x SAT /events/tvc-x-sat
│   └── E-Summit /events/e-summit
├── Speakers /speakers
└── Team /team
```

## Home page sections

1.  Brand reveal --- rocket and wordmark
2.  About TVC --- mission, purpose and approved proof points
3.  What TVC does --- initiatives / ecosystem overview, if content is
    available
4.  Team preview --- selected current members
5.  Contact footer --- approved contact and social destinations

## Events index

Two featured event destinations: - TVC x SAT - E-Summit

Each event panel should show title, concise descriptor, approved visual
and a discover-more affordance. Clicking navigates to its dedicated
detail page.

## Event detail template

1.  Event hero
2.  Overview
3.  Theme / edition
4.  Tracks or programme
5.  Speakers / judges / mentors (if applicable and confirmed)
6.  Partners / sponsors (if applicable and confirmed)
7.  Registration CTA
8.  FAQs / contact (if supplied)

The order may vary based on the event's actual content. Do not force
empty sections into the page.

## Speakers page

-   Introductory statement
-   Speaker archive / gallery
-   Optional grouping by event or edition
-   Speaker detail can be a modal or dedicated route depending on
    content depth

## Team page

-   Intro
-   Leadership
-   Vertical / department groupings
-   Members with approved names, roles and portraits
-   Optional past-team archive in a later release

## Navigation behaviour

-   Current page should be indicated clearly.
-   Event panels must be keyboard-operable links.
-   External registration links should be labelled clearly and may open
    in a new tab with appropriate accessible context.
-   Keep the global navigation consistent across routes.
